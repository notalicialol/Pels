<h4 align="center">Web-based collecting game in which users collect cards of varying rarities and abilities, which are then used in battles with other players to strengthen abilities.</h4>

## Planned Features
Although Pels is still under heavy development and the design of the game is still being worked out, below are some of the planned features for the game:

<!-- More details on features and better formatting later on -->
- Collecting cards -- lots of rare cards can be collected with different rarities and abilities
- Battling other players -- compete with other players to gain XP and coins, which allows advancement of planets and the ability to upgrade cards
- Trading -- the other aspect of the community is being able to chat and trade with other Pels players

## Tech Stack
Currently, the frontend uses:
- React
- TypeScript
- Vite
- Tailwind CSS
- SCSS

## Development Status
As mentioned in the Planned Features section, Pels is very early on in development and a lot of ideas are still experimental. This README will be updated and more formalized as we create a more viable product.
